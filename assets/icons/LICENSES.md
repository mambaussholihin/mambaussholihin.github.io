# Lisensi ikon

Ikon di folder ini dibuat otomatis oleh `tools/build-icons.mjs` dari dua set emoji terbuka.
Nama file adalah kode Unicode emoji (tanpa `fe0f`), misalnya `1f54c.svg` = 🕌.
