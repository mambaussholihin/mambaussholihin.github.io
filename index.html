Publikasikan ke situs

Cara membuat token (cukup sekali)
  1. Buka github.com/settings/personal-access-tokens/new (masuk dengan akun pemilik repositori).
  2. Isi nama bebas, mis. Edit peta pondok, dan pilih masa berlaku.
  3. Repository access → Only select repositories → pilih repositori situs.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Klik Generate token, salin, lalu tempel di kolom di atas.

Token hanya dikirim ke api.github.com dan tidak pernah ditulis di situs.
